# Name and logo policy

The **code** in this repository is licensed under GPL-3.0. See [LICENSE](LICENSE).

The **name "Wormhole X-Treme" and the logo** are not. They are excluded from that licence and
covered by this document instead.

## Why

There is more than one Wormhole X-Treme. This repository is one of several codebases and listings
carrying that name, and a large part of what a mark is for is saying *which one this is*.

Under GPL-3.0 anybody may redistribute and modify any file in the repository, which would include
taking the logo and using it to present a different build as this project. That is the single
outcome the mark exists to prevent, so the mark is carved out and the code is not.

This is the ordinary arrangement for open-source projects with an identity worth protecting --
Rust, Python, Mozilla and the Linux kernel all do some version of it. It takes nothing away from
the code: the plugin remains free software under GPL-3.0, and every right the GPL grants over the
code is untouched.

Copyright and trademark are separate regimes, and the GPL does not pretend otherwise. **GPL-3.0
section 7(e)** expressly permits an additional term declining to grant rights under trademark law.

## What this covers

- The name **Wormhole X-Treme**.
- `docs/images/logo.svg`, `docs/images/logo-banner.svg` and `docs/images/logo-anatomy.svg`, and
  any logo that replaces them.

It does not cover anything else in `docs/images/`. The capture placeholders are throwaway, and
screenshots of Minecraft are a separate question governed by Mojang's terms rather than this
policy.

## What you may do, without asking

- **Use the logo unmodified to refer to this project.** Writing about the plugin, reviewing it,
  linking to it, listing it on a server list or a wiki, illustrating a tutorial about it -- all
  fine, and welcome.
- **Redistribute the plugin jar as built**, logo files included. The jar ships this document.
- **Say your server runs Wormhole X-Treme**, because it does.
- **Fork the code.** The GPL says you may, and this policy does not touch that.

## What needs permission

- **Modifying the logo**, including recolouring it, redrawing it, or building another mark from
  its parts.
- **Using the name or logo for a different distribution, fork or build** in a way that presents it
  as this project.
- **Using either as your own branding** -- for a product, a service, a server network or an
  organisation.

The line is confusion, not commerce. Using the mark to point at this project is what it is for.
Using it to point at something else, or to suggest an endorsement that does not exist, is not.

## Asking

Open an issue. Permission is not hard to get for anything that is not passing another build off as
this one.

## Two honest caveats

**This is not legal advice.** It is a statement of intent by the copyright holder, written by
maintainers rather than lawyers. If the mark ever matters commercially, it deserves a real answer
from somebody qualified to give one.

**The current logo was not drawn by a human.** It was produced in SVG with Claude Code as a
reference for a commission, and copyright protection for machine-generated work is uncertain --
the US Copyright Office requires human authorship, and material generated without sufficient human
creative input is not registrable. Other jurisdictions differ. A carve-out is only as strong as
the copyright behind it, so this policy stands on firmer ground the day a commissioned mark with
assigned copyright replaces the current one. That is another reason for
[issue #187](https://github.com/khanjal/Wormhole-X-Treme/issues/187), beyond the drawing being
better.

The name **Wormhole X-Treme** does not have this problem. Trademark rights come from use in
commerce rather than from authorship, and the name has been in use since 2011.

**This is not retroactive.** The logo files were committed under GPL-3.0 in #184 and sat that way
for a short window before this policy existed. GPL grants are irrevocable, so anybody who took a
copy in that window has a GPL-3.0 licence to *that version* of those files, and nothing here
withdraws it. The practical exposure is small -- days, no tagged release -- but it is true, and
worth knowing rather than discovering. A commissioned replacement (see
[issue #187](https://github.com/khanjal/Wormhole-X-Treme/issues/187)) would start clean under this
policy from its first commit.

## If a logo is commissioned

Any commission must **assign copyright to the project**, not merely license the result. If the
artist keeps the copyright, none of the above is the project's to decide.
