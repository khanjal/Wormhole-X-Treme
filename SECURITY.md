# Security

## Reporting a problem

Please do not open a public issue for a security problem: a way to teleport somewhere a
player should not reach, get round a permission or a toll, crash a server, or read or write
files outside the plugin's folder.

Report it privately instead, through
[GitHub's private vulnerability reporting](https://github.com/khanjal/Wormhole-X-Treme/security/advisories/new).
Only the maintainer sees it. If that is not open to you, message the maintainer on
[Discord](https://discord.com/users/235747179459772416) and say you have a security report,
without the details.

Include the plugin version, the server software and version, and the steps that show it.
Once a fix is released, the advisory is published and you
are credited, unless you would rather not be.

## Supported versions

Fixes go into the latest release only. Older releases are not patched; update to the
latest to get a fix.
