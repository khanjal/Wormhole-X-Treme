# Logo and icon

The full brief is [`docs/LOGO.md`](../../docs/LOGO.md), and the job is tracked in
[issue #187](https://github.com/khanjal/Wormhole-X-Treme/issues/187). This page is the short
version and the delivery list.

## The job

Replace the reference drawing at the top of the README (`docs/images/logo.svg`) with a real
mark. The current one was hand-written in SVG to give an artist something to react to; throw
away any curve in it as long as the new mark does the same job.

- **What it says.** Wormhole teleportation in Minecraft. The current mark carries three
  subsystems (a chevron ring for gates, a column of light for beams, a stack of rings for
  transport rings). A fourth, quantum mirrors, would crowd it; deciding to stop inventorying
  features and simply read as "stargate travel" is a fair answer. Say which you chose.
- **Built for small sizes.** It must read at 32 px, and ideally at 16 px. Design the small icon
  as its own drawing if it needs one, rather than scaling the large mark down.
- **Not the prop.** No reproduction of the TV show's ring, chevrons or glyphs.

## Deliver

- The mark as SVG, in colour and in one colour.
- An icon SVG drawn for 16 and 32 px, if it differs from the mark.
- PNG exports at 16, 32, 64, 128, 256 and 512 px, square, on a transparent background.
- A wordmark set in a real typeface whose licence allows embedding, or outlined in the SVG.
- One page (Markdown or image) on what each element means, so a later redraw keeps the meaning.

## Review

A first sketch round of two or three directions, one chosen direction refined, then finals.
The maintainer checks each at 16, 32 and 512 px, on light and dark GitHub themes.
