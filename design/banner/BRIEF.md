# Banner

The wide images that introduce the plugin: the header of the README and the banners on its
download listings. It follows the [logo](../logo/BRIEF.md) job: start once the logo has a
chosen direction, and use that mark.

## The job

- **README header.** Replaces `docs/images/logo-banner.svg`, shown 620 px wide at the top of
  the README on GitHub, in both light and dark themes. Mark plus wordmark, optionally a tagline.
- **Listing banners.** A header image for each download listing the plugin uses (Modrinth,
  SpigotMC, Hangar). Check each site's current size guidance when you start; they change.
- **Optional: a hero image.** An in-game scene (a gate open in the Research Facility, a ring
  transport mid-beam) for listing galleries. In-game screenshots can come from the facility's
  world viewer; ask for the angles you want.

## Deliver

- README header as SVG, readable on a white and on a near-black page (one file that works on
  both, or a light and a dark file).
- Listing banners as PNG at each listing's size, plus the layered source.
- Text kept as live text or outlined in the source, with the typeface named and its licence.

## Review

One draft of the README header first, checked on GitHub in both themes; the listing banners
follow from the approved header.
